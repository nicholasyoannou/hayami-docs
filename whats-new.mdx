<Update label="Version 0.0.9" description="Unpublished">
  ## v0.0.9 WIP - New platforms & backend additions

  **Features**:

  - Two new discussion platforms added: [**The Anime Community**](https://theanimecommunity.com/) and **Aniwave**.

    **The Anime Community**:
    - Embeds The Anime Community discussion platform & customised colours to support Hayami.

    **Aniwave**:
    - Implemented & indexed **archived** Aniwave comments (thanks to u/Goofhey for the archival work back in 2024) in the backend database including image assets moved to storage solution. Aniwave has been directly added in Hayami as a supported discussion platform and added rendering support for this.
    - Discussion platform settings for Aniwave has been added to auto-load in comments up to a certain depth, if desired also. Aniwave comments are sorted by DISQUS "points" (which is total likes minus dislikes).

  **TBD**: Finish up image serving backend work and clean up database and Hayami to handle this. Do more exhaustive testing around rendering (TBD test image support), add a note that Aniwave is for archived comments only. Ensure The Anime Community mapping to AL/MAL and episode numbers works properly. For Disqus, add 'reply' icon with text of user they're replying to if replying to a parent comment. Also add maximum left-padding numeric amount so continuous discussions don't end up squished to the right of screen.
</Update>

<Update label="Version 0.0.7" description="Published">
  ## v0.0.7 - Initial open beta release (OBT)

  <Info>
    This is an open beta release to double-check and iron out bugs in Hayami to ensure Hayami is the best it can be at a later stage. Hayami will be in a non-bug-free state, so I'd appreciate feedback.
  </Info>
  **Features**: Includes both unauthenticated & software-app authenticated Reddit versions-rendering of comments, fully-verified commenting functionality on both and introducing an ellipsis menu for editing and deleting comments. Fully-functioning image previews across the board, introducing a guide in the documentation on how to retrieve these keys. Settings on Hayami has been sectioned into categories to account for expanding functionality.

  **QOL**: Reddit API will no longer be called _often_ in many scenarios in the event a user has placed multiple comments, and lessens calls to update a subreddit data to weekly.

  **To-do**: Work needs to be done around checking whether profile pictures are fetched properly in niche scenarios (u/deleted, both on authenticated and unauthenticated fronts) and why upon skeleton loading, the profile pictures themselves loading in create a padding-like effect on-load-in. MAL logo needs to be updated to the actual logo instead of the placeholder intended for testing.
</Update>
