Hayami can be downloaded and installed straight from the [Chrome Web Store](https://chromewebstore.google.com/detail/hayami-anime-comments-dis/nhkggpiaeaeeeimohfpchnjobbamfcbg) and [Firefox Addons](https://addons.mozilla.org/en-GB/firefox/addon/hayami/). After installation, a new tab will be made guiding you through the setup.

Through the setup, you may be asked to connect some accounts. Reddit (r/anime discussion threads) is set to as-default which covers a wide-range of anime, but you can freely switch your default discussion platform when Hayami loads up if you choose to.

The extension will then ask for you to set up [Image previews](/image-previews), which, once setup, allows an on-hover image-viewing experience of albums from Imgur and Imagechest used on Reddit. Image previews already works with individual photos, when an album hasn't been hyperlinked. All you need to provide is an Imagechest API Key, as Imgur already works out the box. You can also set it up _later_ through the extension popup, so feel free to skip this step.

<Frame>
  ![Image](/images/image-44.png)
</Frame>

That's it, you're all setup and the extension from that point should work out-the-box on Hayami's supported sites, which currently are **Crunchyroll** and **Netflix**. This doesn't mean you can't setup Hayami elsewhere. With [custom websites](/custom-websites), any site can support Hayami, setup by you. It's extremely simple to use the custom website functionality since it has an element picker, allowing you to pick the anime name, episode number and where you want it mounted with ease.

Custom websites can be imported & exported freely, so individuals or communities that do like to fiddle with the best layout for comments can experiment, and share those about for others to import as they please. For enthusiasts that want to develop community instances that groups many custom websites is done through [KomentoScript](/komento-script), which builds on custom websites syntax further as well.
