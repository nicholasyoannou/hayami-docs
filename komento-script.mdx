<Note>
  The current version of KomentoScript is **v0.1**.
</Note>

<Warning>
  KomentoScript is in early-phase undergoing testing & can be subject to change. Documentation will be more limited during initial development & testing periods.
</Warning>

KomentoScript is a JSON format that tells Hayami which pages to support, how to extract anime/episode info, and where to mount the discussion UI. For more details on creating your own KomentoScripts, please see [KomentoScript (for script-makers)](/komento-script-dev).

KomentoScript is provided by Hayami for official mappings to some sites. To add unofficial mappings, you can do so at your own accord by going to [Guide for client TBC].
