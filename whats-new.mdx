  ## v0.0.8.2 WIP - General & mapping improvements

  **Features**: Improves backend to support date & by-document-ID mapping improving search. Adds date to background workers to account for date mapping search.

  **QOL**:

  - **Aniwave**: Fixed unintended bug where in Aniwave where clicking 'load more comments' when you've de-expanded a top-level thread not related to the comment re-expands that thread.

    **MAL**:
    - Fixed spoiler rendering on MAL not displaying properly (and line break spoiler handling), 'Latest posts' text removed.
    - Fixed signatures having multiple images meant to be on one line instead going on multiple lines. Signature text now also wrapped instead of forcing a single line, preventing overflow beyond the comments container.
    - Quote handling within other's comments now supported.

    **AniList**:
    - Fixed line breaks, increased text size, and ensured post body is included first as it's own comment.
    - Changed formatting for love heart placement on the right hand side, 'Latest comments' removed.
    - Added image embedding support (& grid-view).
  - **Mapping**: Fixed bug where "Kimi no Koto ga Daidaidaidaidaisuki na 100-nin no Kanojo" Season 1 mapped to Season 2 discussions, and ensures date-classification mapping on Crunchyroll is ignored if the date is before March 1st, 2022 (Funimation catalogue merge [screwed over the dates on-site for older series](https://www.crunchyroll.com/series/GY3VKX1MR/hunter-x-hunter)).
  - **Backend**: Added caching rules for Aniwave asset serving endpoints.

  **TBD**: Confirm date mapping on API, do TODO from v0.0.7. Implement date mapping on _most_ websites on Hayami (excl. Crunchyroll unless after March, 1st 2022).

  **QOL TBD**: Check for non-official-supported (manually added sites) external sites that the QOL from 0.0.7 takes into effect. Work on some general patches and fixes from Upcoming features also.
</Update>

<Update label="Version 0.0.8.1" description="Published">
  ## v0.0.8.1 - New platforms & backend additions

  This build adds **two new discussion platforms** as well as introduces some minor QOL improvements.

  **Features**:

  - Two new discussion platforms added: [**The Anime Community**](https://theanimecommunity.com/) and **Aniwave**.

    **The Anime Community**:
    - Embeds The Anime Community discussion platform & customised CSS.
    - Dynamically re-sizes iframe accordingly to height of the embed so the comments section doesn't incidentally get cutoff screen.

    **Aniwave**:
    - Implemented & indexed **archived** Aniwave comments (thanks to u/Goofhey for the [archival work](https://archive.org/details/aniwave-comments.tar) back in 2024) in the backend database including image assets moved to storage solution with direct backend support. Aniwave has been directly added in Hayami as a supported discussion platform and added rendering support for this.
    - Discussion platform settings for Aniwave has been added to auto-load in comments up to a certain depth, if desired also. Aniwave comments are sorted by DISQUS "points" (which is total likes minus dislikes).

      **QOL**:
      - Added 'reply' icon with user they're replying to if replying to a parent comment, which also has a setting to enable/disable if desired.
      - Added maximum left-padding numeric amount so continuous discussions don't end up squished to the right of screen.
      - Added support for comment image displaying.
      - Added note that Aniwave is for archived comments only between 2016-2024, which is also added on no comments found.
      - Fixed name not displaying for Aniwave - some names on Disqus are so unbelievably wacky, usernames are used as a fallback.

  **QOL**: MAL logo updated to the actual logo instead of the placeholder intended for testing.

  **TBD**: Do more exhaustive testing around Aniwave rendering. Ensure The Anime Community mapping to AL/MAL and episode numbers works properly. Add a manual overwride popup on TAC (similar to MAL-Sync), and Aniwave (uses normalised slugs via Hayami API). Add performance enhancements to avatars loading in on Aniwave. [_DebInfo_](/debugging-information)
</Update>

<Update label="Version 0.0.7" description="Published [8th Feb 2026]">
  ## v0.0.7 - Initial open beta release (OBT)

  **Platforms**: Introduces DISQUS, Reddit, MyAnimeList, AniList and YouTube.

  **Features**: Includes both unauthenticated & software-app authenticated Reddit versions-rendering of comments, and commenting functionality on both, introducing an ellipsis menu for editing and deleting comments. Fully-functioning image previews across the board, introducing a guide in the documentation on how to retrieve these keys.

  **QOL**: Reddit API will no longer be called _often_ in many scenarios in the event a user has placed multiple comments, and lessens calls to update a subreddit data to weekly. Settings on Hayami has been sectioned into categories to account for expanding functionality.

  **To-do**: Work needs to be done around checking whether profile pictures are fetched properly in niche scenarios (u/deleted, both on authenticated and unauthenticated fronts) and why upon skeleton loading, the profile pictures themselves loading in create a padding-like effect on-load-in.
</Update>
