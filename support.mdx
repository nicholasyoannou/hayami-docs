This project was created with a pretty simple premise: anyone can comment, anywhere they want, bringing about the project's slogan, "Comments, with you", as you can embed Hayami anywhere you want it to be. The project was stemmed by the shutdown of particular anime streaming sites yielding tens of thousands of comments, to even actions brought about by an official anime streaming site to slash the community aspects from it completely. After a while passed, no proper solution came about, which made me create Hayami, brought into development in November 2025.

Since then, Hayami officially supports Reddit, Disqus, MAL, AniList, The Anime Community, and (hopefully) many more discussion platforms to come in the foreseeable future. All of my work is volunteer-only and completely unpaid, so if you enjoy my work and wish to support it, please feel free to donate. All donations to me will go towards:

- VPS/Dedicated infrastructure: VPS hosting which includes the backend, and databases that map discussions across the web
- Software/hosting licenses: helps me bring about the project in itself
- Third-party IaaS/SaaS: hosting object storage (for archival comments sections), and enabling further discussion platform support \+ enhanced accuracy

Even a small donation will go along way - LiberaPay helps you do this. I'd heavily appreciate monetary contributions to allow for continued maintenance to pay for server costs, and allow for continued features in the future.
